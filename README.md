# LLM 学习与实践

面向已有机器学习、深度学习与 VLN 经验的算法工程师，建立 LLM 数据、后训练、评估与实验分析能力，为转岗准备可验证的项目证据。

更新：2026-11-09。计划按每周 12–15 小时估算，可按掌握情况跳过；阅读完成不等于实验完成。

## 从这里开始

1. 阅读 [个性化学习计划](plans/roadmap.md)。
2. 按 [论文阅读顺序](papers/README.md) 从 InstructGPT → DeepSeekMath → LoRA 开始。
3. 复制 [论文笔记模板](notes/paper-template.md)，记录问题、目标、证据和局限。
4. 按 [首周任务](plans/week-01.md) 完成第一轮阅读和最小计算验证。
5. 使用 [实验模板](experiments/template.md) 记录实验，持续更新 [进度](PROGRESS.md)。

## 已有基础与学习边界

- 有 ML/DL、VLN、自回归 token 预测基础；了解 AdamW、混合精度。
- 已读 GPT-2，仔细读过 Qwen2.5-VL 代码，读过部分 DeepSeek-V3；需要通过回读恢复细节。
- 本机 RTX 5080 16GB。先做小模型、短序列、受控变量实验，按实测显存和吞吐决定是否租卡。
- 不重学注意力、mask、残差等基础章节；遇到具体缺口再补。
- 新训练和评估均尚未执行，不把计划、论文结论写成个人实验成果。
