# 专题：文档知识内化与通用能力保持

## 研究问题

模型能否在不携带原文时回答新问题？新知识收益是否伴随无关能力下降？重复查询的收益能否抵消适配成本？

## 最小范围

从一个或一小组文档的参数适配开始。暂不训练 Doc-to-LoRA 超网络，不声称复现完整论文。选择原模型能处理的语言、任务与长度。

## 基线

1. 原模型，不带文档：测已有知识。
2. 同一原模型，带完整文档：信息可见的对照，不是理论上界。
3. 普通知识蒸馏到 LoRA。
4. 相同训练预算下，LoRA + 一种保留方法（replay 或 KL）。
5. 长文档场景再加入简单 RAG，明确检索与生成成本。

## 评估与数据边界

- 适配可以使用目标文档；最终测试问题不得用于训练、生成训练题或调参。
- 分开开发文档/问题与最终测试；保存构建和筛选过程。
- 测试事实回忆、问题改写、信息组合、数字和实体；区分记忆与推理。
- adapter 开启时测无关任务；关闭恢复基座只能证明可回退。
- 保留评估选择基座确实能完成的任务，避免接近随机分数造成“无退化”错觉。
- 测试集无退化不等于所有能力无损。

## 成本与控制变量

固定基座、量化方式、数据量、训练 token 预算和评估解码设置。记录适配耗时、显存峰值、adapter 大小、查询延迟、预填充与生成 token 数；比较多次查询的累计成本。

首轮只改变一种保留约束。有效后再研究权重系数、rank 或连续更新，避免无法归因。

## 报告

写明问题、相关工作、数据、训练设置、基线、消融、失败、不确定性与局限。负结果可以成为成果，但不能将单模型、少量任务结论外推到所有 LLM。
